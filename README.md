# ✦ Studio Aurora

**Criatividade e tecnologia para criar o próximo.**

O Studio Aurora é um projeto autoral que representa um estúdio independente de tecnologia e criatividade, com foco em desenvolvimento web, software e experimentação digital.

Este repositório contém o desenvolvimento do site institucional do Studio Aurora, criado para apresentar sua identidade visual, projetos e áreas de atuação.

## ✨ Sobre o projeto

O site foi desenvolvido com uma proposta visual moderna e criativa, utilizando um tema escuro, gradientes e elementos gráficos para construir uma identidade tecnológica.

O objetivo foi desenvolver uma página responsiva, organizada e visualmente consistente, colocando em prática conhecimentos de desenvolvimento web.

## 🚀 Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo.
- **CSS3** — estilização, identidade visual, efeitos e responsividade.
- **JavaScript** — funcionalidades e interações da página.
- **Git e GitHub** — versionamento e hospedagem do código.

## 🖥️ Como executar

1. Clone este repositório:

```bash
git clone https://github.com/igutoi/studio-aurora.git
```

2. Entre na pasta:

```bash
cd studio-aurora
```

3. Abra o arquivo `index.html` no navegador.

Você também pode utilizar a extensão **Live Server** no Visual Studio Code para visualizar o projeto durante o desenvolvimento.

## 🎨 Funcionalidades e características

- Layout moderno e responsivo.
- Identidade visual com tema escuro e gradientes.
- Seção de apresentação do estúdio.
- Área dedicada aos projetos.
- Apresentação das áreas de atuação.
- Seção de contato com integração por e-mail.
- Links externos para projetos e GitHub.

## 📌 Projetos em destaque

### Data Center

Projeto acadêmico desenvolvido em Java, com foco na simulação de monitoramento e controle de equipamentos de um Data Center, explorando conceitos de sistemas distribuídos e comunicação entre processos.

**Tecnologias:** Java, gRPC, Protocol Buffers e UDP.

### Studio Aurora

Desenvolvimento do próprio site institucional, utilizando tecnologias fundamentais do desenvolvimento web.

**Tecnologias:** HTML, CSS e JavaScript.
